# irchika.github.io
# Тестовый сайт для аналитики

## Описание

Тестовый сайт для настройки и проверки систем веб-аналитики: Google Tag Manager, Google Analytics 4, Яндекс.Метрика, Meta Pixel и других сервисов.

## Структура

Одна страница (`index.html`), содержащая типовые элементы:

- навигационное меню
- поле поиска
- карточки товаров с кнопками
- форма отправки данных


## Подключение GTM

В коде используется GTM-контейнер.

## Файлы

- `index.html` — основная страница
- `README.md` — этот файл
